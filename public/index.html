怎么订阅

  1. 1
    打开 Apple Calendar，选择 File > New Calendar Subscription...
  2. 2
    粘贴上方订阅地址，自动刷新建议设为每 30 分钟或每小时。
  3. 3
    看到“预告”时先确认日期；看到“空投”时仍以 Binance Wallet > Alpha > Events 为最终领取页。
GitHub Pages 只负责托管日历文件。最终领取资格、Alpha Points 门槛和奖励数量以 Binance Wallet App 内活动页为准。
